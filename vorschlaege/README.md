# Vorschläge zur Entscheidung (Ampel: Gelb)

Jede Datei ist eine Entscheidungsvorlage: `JJJJ-MM-TT-marke-thema.md`.

Aufbau jeder Vorlage:
1. **Worum geht es?** (ein Satz)
2. **Empfehlung** (konkret)
3. **Warum?** (Belege, Links)
4. **Risiko und Aufwand**
5. **Status:** offen · angenommen · abgelehnt (trägt der CEO nach der Antwort des Verlegers ein)
