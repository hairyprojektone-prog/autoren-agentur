# Zahlen

Hier landen die monatlichen KDP-Berichte. So geht es:

1. In KDP anmelden → „Berichte“ → „Lizenzgebühren“ bzw. „Dashboard“ → Monatsbericht als Excel herunterladen.
2. Auf github.com dieses Repository öffnen → Ordner `zahlen` → „Add file“ → „Upload files“ → Datei hineinziehen → „Commit changes“.
3. Dateiname möglichst `JJJJ-MM-kdp.xlsx`.

Der Controller wertet die Datei beim nächsten Monatszyklus aus.
