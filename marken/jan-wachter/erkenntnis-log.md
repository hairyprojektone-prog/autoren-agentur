# Erkenntnis-Log

Was funktioniert und was nicht, mit Beleg. Neueste Einträge oben. Jeder Agent liest dieses Log vor der Arbeit.

Format:
```
## JJJJ-MM-TT · Quelle (Agent)
- Erkenntnis: …
- Beleg: Zahl, Link oder Datei
- Folge: Was wir ab jetzt anders machen
```
